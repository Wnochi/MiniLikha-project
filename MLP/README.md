# Crochet POS - MVP

Simple client-side POS for a small crochet business. Built as an educational MVP using HTML/CSS/JS and localStorage.

Files:
- `login.html` - Login page
- `register.html` - Registration page
- `index.html` - Main POS single-page app
- `style.css` - Styles (light pink theme)
- `auth.js` - Authentication helpers (localStorage)
- `script.js` - Main POS logic (products, cart, admin)

How to run:
1. Open `login.html` in a browser.
2. Default admin: `admin@admin.com` / `admin`.

Notes:
- This is a client-only MVP; data is stored in `localStorage`.
- Images can be provided as URLs or uploaded (stored as base64).
- For next steps, we can improve validation, add edit product, and refine UI interactions.
